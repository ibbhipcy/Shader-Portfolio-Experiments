# Unity Custom Shaders & Graphics Experiments

## Overview
This repository contains a collection of custom Shaders and C# scripts developed in Unity, focusing on rendering techniques and graphics pipeline experiments. 

It includes implementations of:
*   **Dynamic 2D Heatmap:** Distance-based heat rendering with data optimization.
*   **Radar Highlight:** Distance-attenuated radius effect for skill indicators.
*   **Custom Blinn-Phong Lighting:** Hand-coded diffuse and specular lighting with normal mapping.
*   **Post-Processing:** Depth-based blending and BSC color grading.
*   **Screen Grab:** GrabPass for glass/refraction effects.

*Visual demonstrations of these shaders in action are presented in the portfolio PDF.*
